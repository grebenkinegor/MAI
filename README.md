## MoodBoard AI

Краткое описание: веб‑приложение на React + Vite для анализа дизайна сайта по скриншоту и подбора референсов, с сохранением коллекций в Supabase.

## Требования

- Node.js 18+  
- npm (идёт вместе с Node.js)

## Установка зависимостей

В корне проекта выполните:

```bash
npm install
```

или коротко:

```bash
npm i
```

## Запуск в режиме разработки

```bash
npm run dev
```

После запуска Vite покажет адрес (обычно `http://localhost:5173`), откройте его в браузере.

## Сборка проекта

```bash
npm run build
```
